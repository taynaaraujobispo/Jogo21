# Jogo21 🎲

Projeto **Jogo21**, desenvolvido como prática de POO em Java no SENAC, simula o clássico **Blackjack (21)**. Permite partidas entre jogador e computador, controlando cartas, pontuação e regras do jogo de forma automatizada.

![Uploading image.png…]()


## Funcionalidades ✨

- Controle de cartas e pontuação  
- Verificação de estouro (mais de 21 pontos)  
- Determinação automática do vencedor  
- Partidas interativas via console  
- Regras básicas do Blackjack implementadas  

## Tecnologias 🛠️

- Java 21  
- POO (Classes, Encapsulamento, Métodos)
